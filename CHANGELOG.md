# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-xx

### Added
- Initial release of Curated Gifting luxury gift box website
- Responsive design for all devices
- Product filtering by category and occasion
- WhatsApp integration for direct ordering
- Multiple collections (For Her, For Him, Couples, Corporate, Festive)
- Seasonal festive offerings (Diwali, Christmas, Valentine, New Year)
- Custom gift box builder section
- Customer reviews and ratings section
- FAQ section with common questions
- Hero section with call-to-action buttons
- Footer with quick links
- Smooth scrolling and animations
- Mobile-first responsive approach
- CSS variables for easy customization
- Pure vanilla JavaScript (no dependencies)

### Features
- Product cards with images, descriptions, prices, and tags
- Filter pills for easy category selection
- Occasion-based sections
- Festive celebration cards
- Review/testimonial section
- Custom box builder information
- FAQ accordion section
- Floating WhatsApp CTA button
- Modal for custom box details

### Technical
- Minified CSS for better performance
- Optimized JavaScript
- Semantic HTML5
- Mobile breakpoints at 800px and 540px
- CSS Grid and Flexbox layouts
- Smooth scroll behavior
